# The only things to fill in (nothing in the code/results depends on these)

## When you create the GitHub repo
- [ ] Replace `USERNAME` with your GitHub account in `README.md` and `CITATION.cff`
      (repository URL). Put the repository link in the manuscript.

## When you want a citable DOI (do this once, at the end)
- [ ] On the GitHub repo: **Releases → Create a new release**, and enable the
      GitHub–Zenodo integration. Zenodo then mints ONE DOI covering the whole archive
      (code + data). Put that DOI in `README.md` and `CITATION.cff` (`doi:`), and in the
      manuscript's data/code-availability statement.

## On paper acceptance
- [ ] Add the final article citation (title, journal, DOI) to `README.md` / `CITATION.cff`.

Everything else is complete and does not depend on the manuscript text.
